# 🩸 Blood Donation & Management System (Full-Stack)

A modern, full-stack web application designed to connect blood donors with patients in urgent need. The platform features role-based access control, secure authentication (including Google OAuth), emergency blood requests management, and a clean, responsive UI built with Next.js and Tailwind CSS.

## ✨ Features

- **Role-Based Dashboards:** Distinct panels and permissions for Patients, Donors, Providers, and Admins.
- **Emergency Blood Requests:** Patients can create urgent blood requests with details like blood group, bags needed, hospital location, and urgency level.
- **Google Authentication & Local Auth:** Secure login options with automatic redirection and session management.
- **Modern UI/UX:** Built with Tailwind CSS supporting dark/light mode and glassmorphism elements.
- **Form Validation:** Robust client-side validation using React Hook Form and Zod.
- **Toast Notifications:** Real-time feedback alerts for user actions.

---

## 🛠️ Tech Stack

### Frontend:
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, Lucide Icons
- **Form Management:** React Hook Form, Zod resolver
- **State & Routing:** Next.js Router

### Backend & Database:
- **Server:** Node.js, Express.js (RESTful APIs)
- **Database:** Prisma & postgresql
- **Authentication:** JWT (JSON Web Tokens), Google OAuth 2.0
